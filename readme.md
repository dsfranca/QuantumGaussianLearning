# Quantum Gaussian Learning Plot Reproduction

This repository contains numerical code and plotting scripts for reproducing the plots used in the manuscript

> Marco Fanizza, Cambyse Rouze, Daniel Stilck Franca, "Efficient Hamiltonian, structure and trace distance learning of Gaussian states", arXiv:2411.03163.

Paper link: https://arxiv.org/abs/2411.03163

The code focuses on the one-dimensional bosonic Gaussian Hamiltonian examples used to compare global plug-in Hamiltonian reconstruction with local inversion. The manuscript plots in this repository cover:

- reconstruction error versus number of modes for the ill-conditioned chain (`c = 0`);
- reconstruction error versus number of modes for the well-conditioned chain (`c = 0.1`);
- reconstruction error versus locality parameter `l`, including sampled and exact-covariance curves.

## Repository Layout

| Path | Purpose |
| --- | --- |
| `qgl_reproduce.py` | Core Python implementation: covariance generation, sampling, global/local reconstruction, error metrics, and plotting helpers. |
| `run_seeded_reproduction.py` | Command-line pipeline that regenerates seeded CSV data and PNG figures. |
| `dump_plot_matrices.py` | Exports labeled NPZ archives containing the matrices used by the seeded plot pipeline. |
| `push_generated_dumps.sh` | Helper script for staging, committing, and pushing generated dump directories. |
| `reproduce_natcomm_plots.ipynb` | Notebook version of the reproduction workflow, with switches for expensive reruns. |
| `sanity_check_window.py` | Small-window diagnostic comparing reconstructed Hamiltonian submatrices against the target. |
| `reproduction_data/` | Published/historical values used for immediate plot reproduction. |
| `reproduction_data_seeded/` | Outputs from seeded reruns. |
| `reproduced_plots/` | Recreated plots from published/historical values. |
| `reproduced_plots_seeded/` | Plots generated by the seeded command-line pipeline. |
| `plottererrorm.py`, `plotterl.py` | Legacy Python plotting scripts with hard-coded data. |
| `globalvslocal.jl`, `scalingl.jl`, `exact_covariance.jl` | Original Julia simulation scripts. |
| `NatCommResub/` | Manuscript source and figure assets. |

## Python Setup

Use a virtual environment from the repository root:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

The Python workflow depends on NumPy, SciPy, pandas, Matplotlib, and notebook tooling. Matplotlib is configured by the scripts to write its cache under the system temporary directory, so the code can run in restricted or headless environments.

## Quick Smoke Test

Run a small, fast reproduction to verify the environment:

```bash
python run_seeded_reproduction.py --quick
```

This writes a reduced set of CSV files to `reproduction_data_seeded/` and figures to `reproduced_plots_seeded/`. The quick run is intended only as a functional check; it does not use the manuscript-scale parameter grid.

## Reproduce the Seeded Plots

Run the full seeded pipeline:

```bash
python run_seeded_reproduction.py
```

By default this uses:

- inverse-temperature prefactor `beta = 0.5`;
- ill-conditioned chain parameter `c = 0`;
- well-conditioned chain parameter `c = 0.1`;
- mode sweep `m = 100, 150, ..., 1150`;
- `N = 10^4` samples and locality `l = 3` for mode-sweep plots;
- locality sweep at `m = 100` with `N = 10^4` and `N = 10^5` samples;
- locality values `l = 2, 4, 6, 8, 10`.

The full mode sweep can be slow because it repeatedly samples high-dimensional Gaussian distributions and performs dense matrix functions. Useful partial runs:

```bash
python run_seeded_reproduction.py --only mode
python run_seeded_reproduction.py --only locality
```

Generated outputs:

- `reproduced_plots_seeded/simulation_errors_plot_ill.png`
- `reproduced_plots_seeded/simulation_errors_plot_well.png`
- `reproduced_plots_seeded/improved_plot.png`
- matching CSV and JSON metadata under `reproduction_data_seeded/`

## Reproduce Plots Immediately from Stored Values

The notebook can recreate plots from the values already included in this repository without rerunning every expensive simulation:

```bash
jupyter notebook reproduce_natcomm_plots.ipynb
```

Inside the notebook, set:

- `RUN_EXPENSIVE_MODE_SWEEPS = True` to regenerate both mode-sweep CSV files;
- `RUN_EXPENSIVE_L_SWEEP = True` to regenerate the sampled locality curves instead of using stored values.

When these flags are left as `False`, the notebook uses the stored/published data tables where available and copies or recreates the corresponding PNG files quickly.

## Sanity Check

To inspect a small Hamiltonian window and compare local and global estimates:

```bash
python sanity_check_window.py
```

This writes:

- `sanity_checks/window_submatrix_check.csv`
- `sanity_checks/window_submatrix_errors.png`
- `sanity_checks/window_submatrix_summary.json`

The command exits with status `0` if the local max absolute error is below the configured threshold.

## Matrix Data Dump

For a compact audit dump, export a deterministic 5-mode window plus the corresponding full-matrix error values:

```bash
python dump_plot_matrices.py --scope audit --seed 100 --output-dir data
```

This writes a small labeled `.npz` archive, `audit_errors.csv`, `manifest.csv`, `manifest.json`, and `run_config.json` under `data/`. The archive contains a `labels_json` entry describing the arrays inside it.

To export the full matrices behind the seeded locality plot at `m = 100`:

```bash
python dump_plot_matrices.py --seed 100
```

This writes labeled `.npz` archives plus `manifest.csv`, `manifest.json`, and `run_config.json` under `matrix_dumps/`.

The full mode-sweep dump is much larger:

```bash
python dump_plot_matrices.py --scope all --output-dir matrix_dumps_full
```

Add `--include-samples` only if you also need the raw Gaussian samples, since those files can become very large.

To push generated dumps to the configured Git remote:

```bash
./push_generated_dumps.sh --dry-run
./push_generated_dumps.sh -y data
```

The script refuses very large dumps by default and rejects files near GitHub's 100 MB file limit. Use `--include-code` if the same commit should also include the reproduction scripts and README updates.

## Legacy Julia Scripts

The original Julia scripts are kept for reference:

```bash
julia globalvslocal.jl
julia scalingl.jl
julia exact_covariance.jl
```

They require Julia plus the external packages `Distributions` and `Plots`. The other Julia modules used by the scripts (`LinearAlgebra`, `SparseArrays`, `Statistics`, `DelimitedFiles`, `Dates`, and `Printf`) are standard libraries.
